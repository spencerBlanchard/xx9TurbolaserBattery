# xx9TurbolaserBattery
Welcome to the XX-9 Heavy Turbolaser Battery. This was originally made to have audio but the module I was using had a small delay, which kind of killed the gameplay so I got rid of it completely. 
Vibe Coded. 
Runs on esp32 dev kit

A NOTE ABOUT USING THE SERVOS: the MG90S servos are continuous servos, which means you have to spend a gutwrenching number of hours calibrating them. If you want to redo the code and use positional servos, that's probably easier, but my wife says I'm not allowed to spend any more money on this project.
