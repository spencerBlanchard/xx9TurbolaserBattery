# xx9TurbolaserBattery
Welcome to the XX-9 Heavy Turbolaser Battery. This was originally made to have audio but the module I was using had a small delay, which kind of killed the gameplay so I got rid of it completely. 
Vibe Coded. 
Runs on esp32 dev kit
